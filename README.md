Instrucciones:
Abre una terminal en la carpeta del proyecto y entra a src
cd src
compila las clases:
javac Vehiculo.java Automovil.java Motocicleta.java CamionetaCarga.java RentaMovil.java Main.java
y posterior mente ejecuta el programa:
java Main

Uso:
Al iniciar el programa carga dos vehiculos de cada categoria. El menu permite registrar vehiculos, consultar la flota, cotizar, confirmar alquileres, registrar devoluciones y ver el reporte general.
Los datos y los ingresos se conservan unicamente mientras el programa este en ejecucion.

Requisitos
Tener instalada Java JDK 8 o una version posterior.
